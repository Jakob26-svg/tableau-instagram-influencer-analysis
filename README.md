# Instagram Influencer Analysis — Tableau

A Tableau workbook for exploring top Instagram influencers and comparing audience size, posting activity, likes, influence score, and engagement metrics.

## Included

- `Mini final project.twb` — Tableau workbook with six worksheets.

## Data source

The workbook references a local Excel file named `top_insta_influencers_clean.xls`. That source file was not included with the uploaded workbook, so Tableau may ask for the data connection to be relinked when the workbook is opened on another computer.

## Open the project

Open the `.twb` file in Tableau Desktop or Tableau Public and relink the data source if prompted.
